    Detailed Description

    class NW_Sensor;

    What a data logger needs from a sensor library to keep a status file.

    Every library on NW_Core (Apis, Walrus, Haar, Libelle) inherits this and the logger keeps a list of them (Margay::watch()). The logger writes a row for a device when its report says something happened: after a reading, reportKind() is the reading’s report; bootReportKind() is what begin() captured before the first trigger cleared it, kept until the logger has looked (clearBootReport()). A reset (kind 6) seen at boot is expected on a logger that powers its sensors per reading and makes no row; any other boot report, and any report after a reading, does.
