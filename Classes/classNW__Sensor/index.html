    Detailed Description

    class NW_Sensor;

    What a data logger needs from a sensor library to keep a status file.

    Every library on NW_Core (Apis, Walrus, Haar, Libelle) inherits this and the logger keeps a list of them (Margay::watch()). The logger writes a row for a device when its report says something happened: after a reading, reportKind() is the reading’s report; bootReportKind() is what begin() captured before the first trigger cleared it, kept until the logger has looked (clearBootReport()). A reset (kind 6) seen at boot is expected on a logger that powers its sensors per reading and makes no row; any other boot report, and any report after a reading, does.

    function printDataHeader

    virtual size_t printDataHeader(
    Print & out
) =0

    Print this sensor’s summary columns: the means, with whatever statistics columns it has enabled.

    Parameters:

    • out Where to print.

    Return: Bytes printed.

    The logger composes the data file’s header from its own columns and then each watched sensor’s, in watch order, which is also the column order. No row is composed in RAM: the logger passes the open file, and each sensor writes its own columns into it.

    function printDataRow

    virtual size_t printDataRow(
    Print & out
) =0

    Print one summary row, in printDataHeader()’s column order.

    Parameters:

    • out Where to print.

    Return: Bytes printed.

    Takes no reading. The logger acquires first, then writes the row to the card and to the serial monitor, and a row written to two sinks must not acquire twice.

    function defaultAddress

    virtual uint8_t defaultAddress() const =0

    The address this sensor answers at unless told otherwise.

    How a logger builds its own bus-test list from the sensors watch() gave it, rather than being handed a second list that has to stay in step with them (LIBRARY-DESIGN.md section 14).

    function wake

    virtual bool wake(
    uint8_t address
) =0

    Come back on the bus: the logger cut the sensor rail to sleep.

    Parameters:

    • address where to find this sensor.

    Return: True when the sensor answered and passed begin()’s gates.

    The first of the three calls run(logInterval) makes on each watched sensor. The logger passes the address it was given at watch(), so the address is stated once and in one place. A logger is never powered down and answers true.

    function acquire

    virtual bool acquire() =0

    Take this row’s readings and store them, for printDataRow().

    Return: True when a reading was taken.

    Separate from printDataRow() because a row is written to the card and to the serial monitor, and must not be acquired twice.
